Model Routing Desk

这里不是通用 Swagger，也不是聊天页。它服务于你的本地模型网关运维：编辑模型别名、管理环境变量、校验上游 relay，并对 LiteLLM、Open WebUI 与管理页执行受控启停。

用量与额度

展示 token、额度进度、充值记录与供应商真实成本对比。当前版本以手工额度配置和本地 usage 统计为主。

额度进度

每个 API 账户一条进度线，后续也可以扩展成共享 billing pool。

充值记录

录入真实人民币充值金额，用于反推每百万 token 的实际成本。

性价比对比

优先按真实人民币成本排序；如果暂时没有充值记录，则显示 token 与估算项。

模型路由

先配置供应商和 API，再按模型挂接多个上游。支持按模型和按供应商两种方式查看与编辑同一套路由状态。

环境变量与密钥

这里直接维护 `.env`。正式使用时，至少要替换 `LITELLM_MASTER_KEY` 与 `OPEN_WEBUI_SECRET_KEY`，并补齐所有启用模型所需的 Key。

测试与日志

支持直连测试上游 relay，也支持经 LiteLLM 测别名；日志面板用于快速查看启动、鉴权和端口问题。
